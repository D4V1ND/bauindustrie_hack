Where it did well

  • It reads the long text, not just the title. P4/02.03.0051 is titled "Druckrohr PE100-RC TW" (drinking water pressure pipe), but its long text describes a protection pipe for power cables. It was filed under "Kabelschutzrohr" (cable protection pipe).
  • It resolves "as before" items. P4/03.02.0023 is titled only "Leistung wie Position zuletzt in vollem Wortlaut beschrieben". Its long text adds "but removal of a ductile iron pipe DN 300", and it was filed under "Rückbau Rohrleitung" (pipe removal).
  • Identical items stay together. All 7 groups of repeated items in P4 (16 items) got one type each.
  • It agrees with the first test. For P5, the built version and the test run before the build proposed their type lists independently. They put 48 of 50 items in the same trade and gave 35 of 50 the same type name.

Limits to know

  • Surcharges are added into the quantity sums. A surcharge takes the type of the item it belongs to. P4 has about 91 surcharge items among 296. Example: "Rohrgrabenaushub" adds the metres of trench and the metres of a surcharge on the same trench. The sums per type are too high wherever a surcharge shares the unit of its base item.
  • The trade list is a stand-in. 16 items have a sensible type but no fitting trade, because the 17 trades were made up for the first test.
  • The type list changes from run to run. Three P4 runs proposed 73, 74 and 72 types. One of them had no type for hourly rates and put 25 items in "Sonstiges"; this run put none there.
  • Optional items are listed but not summed. P4 has 24; they carry an "optional" label below.
